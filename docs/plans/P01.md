## Amaç ve senaryo

Temiz bir checkout'ta aynı kaynaklardan küçük ASP.NET Core uygulaması ve React web çıktısı üretmek; yerel PostgreSQL ile sağlık kontrolünü çalıştırmak; CI'da aynı kontrolleri tekrarlamak. Bu aşama randevu, kimlik veya firma verisi eklemez.

## Dahil ve hariç kapsam

- Dahil: resmi sürüm/lisans kontrolü, ADR-001, sürüm/lock sabitleme, minimal sunucu ve web, canlılık/veritabanı hazır olma uçları, yerel Compose, non-root imaj, anlamlı temel testler, CI, README ve `.gitignore`.
- Hariç: Identity/Owner/Staff, randevu veri modeli ve migration, SMS, canlı dağıtım, Coolify yapılandırması, gerçek müşteri verisi. Bunlar sonraki aşamaların işidir.

## Bağımlılık, veri ve API etkisi

- SDK: .NET 10.0.401; çalışma zamanı 10.0.12. Node 24 LTS. PostgreSQL 18.6. Paket ve imaj tag/digest uyumu uygulama sırasında doğrulanır.
- `GET /health/live`: uygulama sürecinin yanıt verdiğini gösterir. `GET /health/ready`: PostgreSQL bağlantısı açılabiliyorsa başarılıdır; sır döndürmez. Başka iş API'si yoktur.
- Veritabanı şeması/migration yoktur. Compose verisi named volume'da tutulur; PostgreSQL 18 imajında volume `/var/lib/postgresql` konumuna bağlanır.

## Güvenlik, mahremiyet, maliyet ve geri dönüş

Yerel örnek ayarlar gerçek sır içermez. DB dış ağa yayımlanmaz; geliştirme erişimi yalnız loopback ve ayrı profil ile açılabilir. Uygulama imajı non-root çalışır. Sır/env dosyaları ve cache `.gitignore` içindedir. Bu aşamada para harcama, canlı mesaj ve gerçek kişi verisi yoktur.

Henüz migration yoktur. Kod/dosya değişiklikleri Git ile geri alınabilir; named DB volume yalnız kullanıcının yerel sentetik verisini tutar ve otomatik silinmez. P02'ye geçmeden önce P01 kanıtı [STATUS](../STATUS.md) içine işlenir ve yol haritası gereği onay istenir.

## Kanıt

Başlangıç: Git `main...origin/main` ve temiz çalışma ağacı doğrulandı. Yerelde .NET SDK 10.0.401, Node 24.18.0 ve Docker CLI mevcut; Docker daemon kullanıcı tarafından açıldı. PowerShell `npm.ps1` engelli olduğundan Windows'ta `npm.cmd` kullanılıyor.

- `dotnet restore FirmaRandevu.slnx --locked-mode`, `dotnet build ... --no-restore` (0 uyarı/0 hata), `dotnet test ... --no-restore` (3/3), `dotnet format ... --verify-no-changes --no-restore` geçti. Ağ kısıtlı ilk restore NuGet audit SSL hatası verdi; ağ erişimiyle aynı denetim kapatılmadan tekrarlandı ve geçti.
- `npm.cmd ci --ignore-scripts`, `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd test` (1/1), `npm.cmd run build` ve `npm audit --audit-level=high` (0 bulgu) geçti.
- `docker compose ... config --quiet`, `up -d --build --wait` geçti. `GET /health/live`, `GET /health/ready`, `GET /` HTTP 200. İmaj `USER 1654`; çalışan konteyner uid 1654; `app_user` superuser/createdb/createrole değil.
- `p01_persistence_probe` tablosuna sentetik `korundu` kaydı yazıldı, DB yeniden başlatıldı, kayıt okundu ve tablo kaldırıldı. Bu restart kalıcılığı kanıtıdır; yedekten restore testi değildir.
- Projeye özel `.gitignore` için `git check-ignore` ile `deploy/.env`, yerel önbellekler, `node_modules` ve üretilen `wwwroot` doğrulandı. `.env.example` takip edilebilir.
- [GitHub Actions](../../.github/workflows/ci.yml) yerel kapıları, imajı ve DB restart'ını tekrarlar. Değişiklikler henüz uzak depoya gönderilmediği için gerçek CI sonucu bekleniyor.
